# db_kebun_binatang
Aplikasi kebun binatang, jadi di kebun binatang ku ada tabel hewan, kandang, pakan, perawatan, petugas. tabel hewan buat melihat berbagai hewan. tabel kandang buat bikin kandang baru. tabel pakan buat makanan untuk hewannya. tabel perawatan buat meriksa hewannya, misalnya hewannya sakit atau sehat. tabel petugas buat ngawasin hewannya
